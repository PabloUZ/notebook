# Configure Scripts

All scripts live in the root `package.json` — the same one generated by `ng new`. Since everything lives in the same root, there's no need for `cd renderer` anywhere; `ng build` and `ng serve` work directly.

---

## `package.json`

```json
{
  "main": "dist/electron/main.js",
  "scripts": {
    "ng": "ng",
    "build:electron": "tsc -p electron/tsconfig.json",
    "build:renderer": "ng build",
    "build": "npm run build:electron && npm run build:renderer",
    "rebuild:native": "electron-rebuild -f -w better-sqlite3",
    "dev:renderer": "ng serve",
    "dev:electron": "tsc -p electron/tsconfig.json -w",
    "dev": "concurrently -k \"npm:dev:renderer\" \"npm:dev:electron\" \"wait-on http://localhost:4200 dist/electron/main.js && electron .\"",
    "start": "npm run build && electron .",
    "dist": "npm run build && electron-builder"
  }
}
```

### What Each Script Does

| Script | Purpose |
|---|---|
| `build:electron` | Compiles `electron/` with its own `tsconfig.json` |
| `build:renderer` | Builds the Angular app |
| `build` | Runs both builds in sequence |
| `rebuild:native` | Recompiles native modules (e.g. `better-sqlite3`) against Electron's Node |
| `dev` | Runs Angular in watch mode, compiles Electron in watch mode, waits for both to be ready, and launches the window |
| `start` | Full build followed by launching Electron — closer to a production run |
| `dist` | Full build followed by `electron-builder`, producing the final installer |

---

## Rebuild Native Modules

`better-sqlite3` is a native module — it's compiled to a binary (`.node` file) for a specific Node.js ABI version. Electron ships its own embedded Node.js, which almost never matches the Node version installed on your system, so a module compiled for system Node won't load inside Electron.

After installing `better-sqlite3` (or any other native module), always run:

```bash
npm run rebuild:native
```

This recompiles the binary against Electron's Node version using `@electron/rebuild`. Run it again any time you reinstall `node_modules` from scratch or change the Electron version — skipping it is what causes errors like `NODE_MODULE_VERSION 127 vs 148 required`.

---

## Recommended Order to Verify Everything Works

1. `npm run build:electron` → confirms it compiles without decorator errors
2. `npm run dev:renderer` in a separate terminal → confirms Angular serves at `localhost:4200`
3. `npm run rebuild:native` → ensures `better-sqlite3` is compiled for Electron
4. `npm run dev` → should open the Electron window loading Angular in dev mode, with TypeORM initializing the SQLite database in the user data folder
